NIELSEN DIGITAL PORTFOLIO

Open index.html in a browser to view the portfolio. Keep index.html, styles.css,
script.js, and Nielsen-Digital-logo.png together in the same folder.

ADD A WEBSITE

1. Open script.js in a text editor.
2. Add another object to the `projects` array, following this pattern:

  { name: "My New Website", url: "https://example.com/", description: "A short introduction to this project." }

3. Put a comma after the previous project's closing brace. Save the file.

The new project appears as a tab automatically. The preview is embedded in the
page when the target site permits embedding; the Visit website button always
opens the site directly in a new tab.
